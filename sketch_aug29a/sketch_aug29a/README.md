# Kiosk Motor Control

Arduino UNO를 이용하여 키오스크의 높이 조절 모터를 제어하는 프로그램입니다.

VL53L0X 거리센서로 사용자의 접근 여부를 감지하고,
스텝모터를 이용하여 키오스크 화면 높이를 자동으로 조절합니다.

또한 결제 완료 신호를 수신하면 키오스크를 최하단 위치로 복귀시킵니다.

---

## 주요 기능

- VL53L0X 거리센서를 이용한 사용자 감지
- 스텝모터 기반 키오스크 높이 조절
- 사용자 감지 시 단계적으로 상승
- 사용자를 놓친 경우 단계적으로 하강
- 상단 / 하단 리미트 스위치를 이용한 이동 제한
- 전원 인가 시 자동 하단 원점 설정
- 결제 완료 후 자동 하단 복귀
- 기존 사용자가 떠난 후 새로운 사용자 감지 시작

---

## 동작 과정

```text
사용자 접근
   ↓
VL53L0X 거리 측정
   ↓
사용자 감지
   ↓
키오스크 상승
   ↓
사용자 위치 탐색
   ↓
적정 위치에서 정지
```

사용자가 감지되지 않으면 키오스크가 단계적으로 하강하여
사용자의 위치를 다시 탐색합니다.

결제가 완료되면 다음과 같이 동작합니다.

```text
결제 완료 신호 H
   ↓
Arduino UNO
   ↓
스텝모터 하강
   ↓
하단 리미트 스위치 감지
   ↓
모터 정지
```

## 거리센서 설정

현재 사용자 감지 거리는 다음과 같이 설정되어 있습니다.

```cpp
const int DETECT_DISTANCE_MM = 1200;
```

사용자가 약 **120cm 이내**에 있을 경우 감지 대상으로 판단합니다.

거리 측정의 안정성을 높이기 위해 한 번의 측정값만 사용하지 않고
총 5번 측정합니다.

```cpp
const byte MEASUREMENT_COUNT = 5;
const byte REQUIRED_DETECTION_COUNT = 3;
```

5번의 측정 중 3번 이상 사용자가 감지되면
최종적으로 사용자가 있다고 판단합니다.

---

## 높이 조절

사용자가 감지되면 키오스크를 다음 거리만큼 상승시킵니다.

```cpp
const long UP_DISTANCE_CM = 10;
```

사용자를 놓친 경우 다음 거리만큼 하강하면서 다시 탐색합니다.

```cpp
const long DOWN_DISTANCE_CM = 3;
```

즉,

```text
사용자 감지
→ 10cm 상승
→ 다시 거리 측정

사용자 미감지
→ 3cm 하강
→ 다시 거리 측정
```

방식으로 사용자의 위치에 맞는 높이를 탐색합니다.

---

## 리미트 스위치

모터가 이동 가능한 범위를 벗어나지 않도록
상단과 하단에 리미트 스위치를 사용합니다.

| Arduino Pin | 기능 |
|---|---|
| D4 | 하단 리미트 스위치 |
| D5 | 상단 리미트 스위치 |

리미트 스위치는 `INPUT_PULLUP` 방식으로 사용하며,
스위치가 눌리면 `LOW`로 인식합니다.

전원을 켜면 먼저 하단 리미트 스위치까지 이동하여
현재 위치를 `0cm`로 설정합니다.

---

## 모터 제어 핀

| Arduino Pin | 기능 |
|---|---|
| D2 | Motor DIR |
| D3 | Motor STEP |

모터 방향은 다음 값으로 설정되어 있습니다.

```cpp
const byte UP_DIRECTION = HIGH;
const byte DOWN_DIRECTION = LOW;
```

실제 모터의 상승 / 하강 방향이 반대로 동작할 경우
`HIGH`와 `LOW` 값을 서로 변경할 수 있습니다.

---

## 결제 완료 신호

현재 Arduino 코드는 `SoftwareSerial`을 이용하여
결제 완료 명령을 수신합니다.

```cpp
SoftwareSerial esp32Serial(6, 7);
```

현재 연결은 다음과 같습니다.

```text
ESP32 TXD → Arduino D6
ESP32 GND → Arduino GND
```

통신 속도는 다음과 같습니다.

```text
9600 baud
```

`H` 또는 `h` 명령을 수신하면 결제가 완료된 것으로 판단하고
키오스크를 하단 리미트 위치까지 자동으로 이동시킵니다.

결제 완료 후에는 기존 사용자가 키오스크 앞에서 떠날 때까지
다시 상승하지 않도록 설정되어 있습니다.

```text

```

키오스크 높이 조절 시스템의 메인 Arduino 프로그램입니다.

## 전체 프로젝트에서의 역할

이 폴더는 전체 **Senior-Friendly-Kiosk** 프로젝트에서
키오스크의 자동 높이 조절 기능을 담당합니다.

```text
VL53L0X
   ↓
Arduino UNO
   ↓
사용자 감지
   ↓
Step Motor
   ↓
Kiosk Height Control
```

결제가 완료되면 모터를 최하단 위치로 복귀시켜
다음 사용자를 기다립니다.
